# Agent export

Put the exported agent file here.

Conversational Agents console → Agent Overview (or the three-dot menu next to
the agent selector) → **Export**.

This is the only version-controlled form of the console work. The playbook
instructions, tool registrations and data store wiring all live inside Google's
console — when the project is deleted, they go with it. This file is what lets
someone restore the agent into their own project.
